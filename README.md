## How to run a project

Open the project's folder and follow its README.

- Static apps (calculator, weather, quiz, portfolio, pomodoro): open `index.html`, or run `npx --yes serve .`
- React apps (expense tracker, recipe finder, and the Advanced React series): `npm install` then `npm run dev`
- Apps that use Supabase (notes, chat): copy `.env.example` to `.env.local`, paste your own project URL and publishable key, run the SQL in `supabase/schema.sql`, then `npm install` and `npm run dev`
